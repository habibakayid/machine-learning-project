# Dataset distribution decision

Checked 2026-11-18. Kaggle Flowers Recognition by Alexander Mamaev, Version 2: the Kaggle data card lists its license as **Unknown**. It reports 4317 files in the data explorer, despite older descriptive text mentioning 4242. The local collection contains 4317 photos. This package does not claim permission to redistribute those original photographs.

Source: https://www.kaggle.com/alxmamaev/flowers-recognition/data

Original Kaggle JPEGs, resized pixel arrays, GUI photo screenshots and the sample contact sheet are deliberately omitted. Frozen inventories and hashes, image audits, code, features, trained models and numeric result plots are preserved. Obtain the dataset from Kaggle yourself and import it using the documented command. Existing locally held copies can also be imported. The original project was not altered.

Supplemental iNaturalist photos are included only where an existing manifest retains a CC0, CC BY or CC BY-SA license, source photo/observation URL and attribution. Keep supplemental_field/PHOTO_ATTRIBUTION.csv with those images. License references: https://creativecommons.org/publicdomain/zero/1.0/ , https://creativecommons.org/licenses/by/4.0/ , https://creativecommons.org/licenses/by-sa/4.0/ . Per-image source records remain authoritative; consult the linked observation for license details. Photos without such retained records are omitted.
